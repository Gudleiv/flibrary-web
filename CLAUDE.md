# flibrary-web

Веб-каталогизатор электронной библиотеки поверх коллекции
[FLibrary](https://github.com/heimdallr/books): SPA на Vue 3 + PrimeVue 4 и API на Fastify.
Аутентификация базовая, без регистрации. Главная фича — расширенный поиск.

Обзор и быстрый старт — в `README.md`. Обоснование архитектурных решений — в
`docs/decisions.md` (читать перед тем, как менять что-то из перечисленного там).
Полный план — `docs/architecture.md`.

## Инварианты

Нарушение любого из них — не «стилистическая правка», а поломка того, на чём стоит проект.

1. **В коллекционную БД не пишем никогда.** Её схемой владеет FLibrary: она создаётся при
   импорте inpx и меняется миграциями, любые наши таблицы там были бы снесены. Технически
   это обеспечено тем, что коллекция подключена через `ATTACH` к соединению, открытому
   с флагом READONLY (`src/db/index.ts`). Если понадобится процесс, который читает коллекцию
   и пишет что-то своё, — это два разных соединения (см. индексатор).
2. **Все литералы в SQL — только через биндинг.** Никакой конкатенации пользовательского
   ввода: в C++-сервере FLibrary это как раз сделано неправильно, и мы это не повторяем.
3. **Контракт — источник истины.** `packages/contract/openapi.yaml`; из него генерируются
   и TS-типы, и JSON Schema для рантайм-валидации. Руками формы запросов и ответов не
   описываем, иначе клиент и сервер разъедутся.
4. **Закрыто по умолчанию.** Маршрут доступен без аутентификации, только если явно помечен
   `config: { public: true }`.
5. **Работу с файлами книг не переписываем.** Распаковка zip/7z, восстановление картинок в
   fb2, обложки, конвертеры — это C++-сервер FLibrary, мы его проксируем (`src/content/opds.ts`).

## Структура

```
packages/
  contract/   openapi.yaml + генерация типов и JSON Schema
  api/        Fastify
    src/search/   компилятор дерева предикатов в SQL, стеммер, курсоры
    src/indexer/  собственный поисковый индекс (см. README внутри)
    src/db/       collection.db (ro) + app.db (rw), миграции
    src/routes/   auth, search, books, catalog
    src/content/  клиент C++-сервера — единственное место, знающее его контракт
  web/        Vue 3 + TS + PrimeVue 4 + Pinia + TanStack Query
fixtures/     генератор синтетической коллекции по схеме FLibrary
deploy/       docker-compose (+ SMB-оверрейд), Caddyfile, Dockerfile api/web/opds
```

## Команды

```bash
pnpm dev                                  # api :3000 + web :5173
pnpm typecheck && pnpm lint               # обязательно перед коммитом
pnpm --filter @flibrary/api test          # 73 теста, нужны фикстуры
pnpm --filter @flibrary/contract build    # после правки openapi.yaml — обязательно
pnpm fixtures -- --books=50000            # объём для замеров производительности
pnpm --filter @flibrary/api reindex       # пересобрать поисковый индекс
pnpm --filter @flibrary/api users add <логин> <пароль> [имя]
```

В облачных сессиях всё перечисленное, кроме `dev`, уже сделано SessionStart-хуком:
зависимости, контракт, фикстуры (5 000 книг), индекс и пользователь `dev` / `dev`.

## Соглашения

- Комментарии объясняют **почему**, а не что: «два соединения, потому что READONLY
  распространяется на присоединённые БД», а не «открываем базу».
- Обнаруженные особенности данных FLibrary фиксируются в комментарии рядом с кодом —
  их дорого находить заново (`Ext` хранится с точкой, `SearchTitle` это uppercase,
  название жанра лежит в `GenreAlias`, а не в пустом `GenreTitle`, FTS5 `MATCH` требует
  неквалифицированное имя таблицы и не работает с алиасом).
- Ограничения не замалчиваем: если предикат не поддержан — 400 с объяснением, а не пустая
  выдача (`hasCover`, подстрока по аннотации).
- Тексты пользователю и комментарии — по-русски, идентификаторы — по-английски.
- Prettier и ESLint настроены, `pnpm format` перед коммитом.

## Что не готово

Актуальный список — в `README.md`, раздел «Что в поиске ещё не готово», и в конце
`docs/architecture.md`. Коротко: сохранённые поиски, ручка пер-юзер данных,
UI-конструктор запросов, читалка, `hasCover`.

## Чего делать не нужно

- Не собирать C++-сервер FLibrary из исходников: он требует Qt 6.10+ и зависимостей Conan —
  часы сборки. Если нужны обложки и скачивание, он поднимается из официального релиза:
  `apt install weston libegl1 libopengl0 && scripts/opds-local.sh` (грабли — `docs/deploy.md`).
  Без него бинарные ручки отдают 502, и это ожидаемо.
- Не коммитить `data/` — это локальные фикстуры и кэш.
- Не править `packages/contract/src/generated/` — он генерируется.
